    Q2 · Difference equation

    2y[n] + 4y[n − 1] = 6x[n − 2], with x[n] = u[n + 5].

    A recurrence in three coordinates

    3D model

    Each point records the sample index, previous output and current output. Move one step forward. The old current value becomes the new previous value. The next height then follows from the recurrence.

    Green path · successive samples. Amber point · selected sample.

    Drag to rotate · arrow keys when focused
    (a) Find y[n] for every integer n

    Find the first affected sample

    Divide the equation by 2 and move the previous output to the right. The delayed input is x[n − 2] = u[(n − 2) + 5] = u[n + 3]. It first turns on at n = −3.

    y[n] = 3u[n + 3] − 2y[n − 1]

    The causal LTI response starts at zero before the delayed input arrives. At n = −3 the previous output is zero, so y[−3] = 3. At the next sample, y[−2] = 3 − 2(3) = −3.

    Move right from n = −3. Orange is the newest output and green shows earlier samples. The vertical scale adjusts as the sequence grows. Each stem represents one integer sample.

    Why does the first output arrive at −3?

    The original input switches on at −5. The equation reads the input two samples late. At n = −4 it reads x[−6] = 0. At n = −3 it finally reads x[−5] = 1.

    Calculate one more sample by hand. At n = −1 the previous output is −3. Multiplying it by −2 gives +6. Adding the current input contribution gives y[−1] = 6 + 3 = 9.

    Turn the pattern into a formula

    From n = −3 onward, each new output is 3 minus twice the previous one. Expanding the recurrence gives 3 at the first sample, 3[1 + (−2)] at the second, then 3[1 + (−2) + (−2)²]. At index n there are n + 4 terms.

    3 ∑m=0n+3 (−2)m = 3[1 − (−2)n+4]/[1 − (−2)]

    For example, n = −1 gives three terms: 3[1 − 2 + 4] = 9. In general, the last exponent is n + 3. Counting exponents from zero gives n + 4 terms, which is why the geometric-series formula contains the exponent n + 4.

    y[n] = 0 for n < −3, and y[n] = 1 − (−2)n+4 for n ≥ −3.

    Requested samples: y[−4] = 0, y[−2] = −3, and y[0] = −15.

    (b) Decide whether the system is stable

    BIBO stability requires every bounded input to give a bounded output. Our input takes only the values 0 and 1. Its output starts 3, −3, 9, −15, 33, … and the term (−2)n+4 grows in magnitude without limit.

    The system is BIBO unstable. This bounded input gives an unbounded output.

    Q4 · Periodic waveform and Fourier series

    Read one cycle from Figure 2, starting at t = 0. Its three successive heights are −4, 0 and 2.

    One Fourier harmonic in motion

    3D model

    Look along the time axis: the rotating tip traces a circle. Look from the side: its real coordinate traces a sinusoid. The conjugate harmonic has the opposite imaginary part, so adding the pair doubles the real part.

    Green helix · complex harmonic. Amber curve · real part on the Im = 0 plane.

    Drag to rotate · arrow keys when focused
    (a) Read the period and frequency

    The drop from +2 to −4 is at t = 0, then at 4, then at 8. Each pair of consecutive drops encloses one complete pattern.

    T₀ = 4 s · f₀ = 1/T₀ = ¼ Hz · Ω₀ = 2π/T₀ = π/2 rad/s.
    (b) Compute average power over one period

    Square each height and weight it by its duration. The first two pieces last one second each, and the positive piece lasts two seconds. Divide by the four-second period.

    P = [ (−4)² × 1 + 0² × 1 + 2² × 2 ] / 4 = 24 / 4 = 6.
    (c) Derive every Fourier coefficient

    Handle k = 0 first

    In the complex series x(t) = ∑ akejkΩ₀t, the coefficient a₀ is the average height. The negative area is −4 × 1 and the positive area is 2 × 2.

    a₀ = (−4 + 0 + 4) / 4 = 0.

    For k ≠ 0, integrate the two nonzero pieces

    Let b = kπ/2. The middle interval contributes zero. Pull each constant height outside its integral.

    ak = ¼ [ −4 ∫₀¹ e−jbt dt + 2 ∫₂⁴ e−jbt dt ]

    Integrating the exponential gives e−jbt/(−jb). Evaluating at the upper and lower limits gives the following two terms.

    ak = [−4(1 − e−jb) + 2(e−j2b − e−j4b)] / (4jb)

    For an integer k, e−j4b = e−j2πk = 1 and e−j2b = (−1)k. Substitute b and simplify.

    ak = [−3 + 2e−jkπ/2 + (−1)k] / (jkπ), for every integer k ≠ 0.

    Work through the first harmonic, k = 1

    Here b = π/2. On the interval from 2 to 4, the exponential at t = 2 is e−jπ = −1. At t = 4 it is e−j2π = 1. Thus ∫₂⁴ e−jbtdt = (−1 − 1)/(jb). The separate factor 2 multiplying this integral is the height of the waveform from 2 to 4.

    In the final expression use e−jπ/2 = −j. The numerator becomes −3 − 2j − 1 = −4 − 2j. Dividing by jπ gives a₁ = (−2 + 4j)/π. Since the signal is real, a₋₁ is its complex conjugate, (−2 − 4j)/π.

    Dashed green is the original signal. Solid orange is the sum. At N = 0 the line is flat because the average is zero. Set N = 1, then increase it. Each pair adds a real oscillation, 2 Re(aₖejkΩ₀t), and the flat portions take shape. Near a jump, the finite sum has ripples.

    Q5 · Frequency response

    The system satisfies y(t) + (1/a)y′(t) = x(t) − ax′(t). The equation requires a real a ≠ 0 because it contains 1/a.

    Frequency response in the complex plane

    3D model

    Slide Ω to move the spoke. In its fixed-frequency plane the spoke length is the gain, and the angle from the positive real axis is the phase. Look along the frequency axis to see the complex-plane view.

    Green curve · H at each frequency. Amber spoke · H at the selected frequency.

    Drag to rotate · arrow keys when focused
    (a) Find H(jΩ)

    Replace each derivative in the Fourier domain

    A time derivative multiplies the Fourier transform by jΩ. So y′ becomes jΩY and x′ becomes jΩX. Keep the coefficients and signs from the original equation.

    Y + (jΩ/a)Y = X − jaΩX

    Factor out Y on the left and X on the right. Then divide to isolate the output-to-input ratio.

    H(jΩ) = Y/X = (1 − jaΩ) / (1 + jΩ/a).
    (b) Find magnitude and phase

    Magnitude

    The length of 1 + jb is √(1 + b²). Take the length of each complex number, then divide.

    |H(jΩ)| = √[(1 + a²Ω²) / (1 + Ω²/a²)].

    Phase

    The two complex numbers each have real part 1, so their angles are given directly by arctan(imaginary part). For a quotient, subtract the denominator’s angle from the numerator’s angle.

    ∠H(jΩ) = −arctan(aΩ) − arctan(Ω/a) radians.

    Check Ω = 0: the derivatives contribute zero, giving H(0) = 1, magnitude 1 and phase 0.

    What does H do to a sinusoid?

    Try a = 1 and Ω = 1. The numerator 1 − j has length √2 and angle −45°. The denominator 1 + j has length √2 and angle +45°. The ratio has length 1 and angle −90°.

    H(j) = (1 − j)/(1 + j) = −j. A sinusoidal input cos(t) gives cos(t − π/2) = sin(t) in sinusoidal steady state.

    Keep a = 1 and slide Ω. The magnitude stays at 1 because numerator and denominator have equal lengths. Switch to a = 2 to see why that equality depends on a.

    The orange markers use the same Ω. For a unit-amplitude input cosine, the left graph gives the output amplitude and the right gives the angle added to Ωt.

    Q6 · A left-sided impulse response

    h(t) = etu(−t). The step u(−t) selects t ≤ 0, so the exponential approaches zero as t goes farther into the past.

    Slice the convolution integral

    3D model

    Fix t with the slider, then scan across τ. The slice rises above zero only where t ≤ τ ≤ 0. The area under this one slice gives a single output value y(t).

    Green surface · integrand. Amber slice · area integrated at the selected t.

    Drag to rotate · arrow keys when focused
    (a) Test causality

    A causal LTI system must have h(t) = 0 for every t < 0. Try t = −1. The step is u(1) = 1, so h(−1) = e−1, which is nonzero.

    The system is noncausal.
    (b) Test stability

    For BIBO stability, integrate |h(t)| over all time. Only the negative-time part contributes. Its magnitude equals et.

    ∫−∞0 et dt = [et]−∞0 = 1 − 0 = 1.
    The absolute integral is finite. The system is BIBO stable.
    (c) Find the differential equation

    Transform h(t). Multiply by e−jΩt and integrate from −∞ to 0. Combining the exponentials gives e(1−jΩ)t.

    H(jΩ) = [e(1−jΩ)t / (1 − jΩ)]−∞0 = 1 / (1 − jΩ)

    Use Y = HX and multiply by the denominator: (1 − jΩ)Y = X. The term jΩY transforms back to the derivative of y.

    To check the sign of the derivative, differentiate h(t) directly in the distribution sense. Away from zero, h′ = h. At zero the height drops from 1 to 0, which contributes −δ(t) to h′. Hence h − h′ = δ(t). Convolving both sides with x gives y − y′ = x.

    y(t) − dy(t)/dt = x(t).
    (d) Find the output for x(t) = u(−t)

    Find where the two factors overlap

    Write y(t) = ∫ h(τ)x(t − τ) dτ. In this integral, t is the time where you want the answer. The integration variable τ moves through the possible overlaps.

    h(τ) is active for τ ≤ 0.
    x(t − τ) = u(τ − t) is active for τ ≥ t.

    For t < 0, the overlap runs from t to 0. For t > 0, no number τ can satisfy both conditions. At t = 0 the overlap has zero width.

    For t < 0: y(t) = ∫t0 eτ dτ = e⁰ − et = 1 − et.
    y(t) = 1 − et for t < 0, and 0 for t ≥ 0.

    Green is h(τ), and the dashed blue step is x(t − τ). The shaded area on the left becomes the height of the orange point on the right.

    Try three times

    t = −1. The blue step is on from τ = −1 onward. The exponential ends at τ = 0. The shared area is ∫₋₁⁰ eτdτ = 1 − e−1 ≈ 0.632.

    t = 0. The factors touch at a single point. It has zero width, so the integral is zero.

    t = 1. The step starts at τ = 1, after the exponential has ended. Their product is zero for every τ.
